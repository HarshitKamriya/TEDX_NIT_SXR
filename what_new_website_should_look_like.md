# TEDx NIT Srinagar Website Design Prompt

## Project Overview

Design and develop a premium, immersive, modern, and visually stunning website for **TEDx NIT Srinagar** based on the official sponsorship/theme document.

The website should **NOT** look like a traditional college event website.

Instead, it should feel like a **cinematic storytelling experience** that emotionally conveys the year's theme:

# "Innovation Thrives Under Constraints"

The design should communicate that limitations create creativity, resilience, transformation, and breakthrough innovation.

The website should look comparable to award-winning experiences seen on:

- Awwwards
- Apple Events
- Nike Campaign Pages
- SpaceX
- Stripe
- TED Official

---

# Design Philosophy

The website should feel:

- Premium
- Minimal
- Cinematic
- Emotional
- Interactive
- Futuristic
- Elegant
- Bold
- High-performance

Every section should tell part of the story.

Visitors should feel they are experiencing an event rather than browsing a website.

---

# Theme Inspiration

Innovation does not happen despite constraints.

Innovation happens because of constraints.

Visual storytelling should symbolize:

- Fire
- Phoenix
- Broken chains
- Light emerging from darkness
- Sparks
- Mountains
- Determination
- Human imagination
- Infinite possibilities

Avoid cliché AI graphics.

Use symbolic visual language.
